# Architecture

KPP is the primary maintained project, implemented in `mantleos.kpp` within the shared KPP/MantleOS system. The `kpp` command aliases that implementation. [SYSTEMS.md](../SYSTEMS.md) is the common definition of Anchors, CELLs, execution, scanning, Body, memory and carriers. No separate KPP Anchor model exists. [PROJECT.md](PROJECT.md) describes source ownership and promotion to MantleOS.

Recipe declares product, construction, delivery, ingredients, target, Fidelity and measurable obligations. Recipe/3 retains its Anchor binding; recipe/4 has explicit implementation choices and optional shared-neutral binding. Generic workflow and graph validation do not invoke the Anchor model for unbound recipes. Pantry exposes contracts. Scan observes; Chase schedules; Oven proposes; operator admits effects; Baker accepts evidence.

core validates current contracts and strict JSON. workshop owns pinned state, native writer serialization, source admission/activation and receipts. graph derives coverage and Chase. gui uses the shared MantleOS bounded Qt extractor. conformance owns source-bound captures, comparisons and independent per-entry observations; png is a separate bounded codec. GUI evidence joins the same graph without a second approval registry.

Browser products share assets/progressive.js. Product base owns independent Body data and its JSON adapter. Managed resources enable bounded rollback/withdrawal. Source integrity, context evidence and authority remain distinct.

adaptation provides advisory fit; reflex stages approved bounded Python adapters separately; testing runs reviewed local checks. portability uses one strict carrier implementation for Reflex/preview transport, clearing incoming approval.

CELL remains kernel-relative, separate from codecs/carriers/stores/authority. Composition has no fixed organ count. Body behavior survives absent MIND. Retained current-workspace executable tissue serves recovery; superseded kitchen compatibility code is removed. Core runtime is Python standard library, plus a browser for browser products.
