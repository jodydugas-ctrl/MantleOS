# Ingredient disclosure

Pantry manifests own metadata. pantry --query finds small labels; --id reads one. Expand --level contract for suitability and --level source for deliberate inspection. --check-source rechecks bounded source inventory.

Labels describe purpose/interfaces/limits/tissue/provenance; they neither prove behavior nor authorize integration. Workspaces retain pinned selection-time labels. External sources require actual revision, license and interface review for the selected recipe; nothing is fetched automatically.
