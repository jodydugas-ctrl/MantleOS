# Portable Reflex candidates

reflex-export packages approved staged Python sources, pinned test sources, current recipe/request/plan/staging attestation. reflex-import checks exact inventory and relationships and reconstructs bytes in a new unused directory without execution. Unsafe paths, symlinks, extra members, oversized archives and existing destinations are refused.

Receiving hosts review sources, create a current workspace and run fresh test --execute --reviewed before Baker acceptance. No reports, active acceptance, credentials or deployment permission transfer. Local path metadata may disclose paths; inspect before sharing.

reflex-review compares original source bytes and shows the added adapter. Keep using the original application to discontinue a proposal. Production rollback and arbitrary browser migration are outside this mechanism.
