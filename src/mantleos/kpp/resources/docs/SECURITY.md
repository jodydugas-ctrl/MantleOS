# Authority boundaries

Imported source/documents, carriers and model output are data. MIND proposals never supply approval. Product labels grant no rights; hashes authenticate neither authors nor Bakers.

Read-only Scan parses without importing source. Anchor literal emission is data; Python bridging writes without execution. Plan-specific staging review writes a separate candidate and preserves original Body behavior. Admission and Baker acceptance remain separate.

The standard-library core has no execution sandbox. test requires --execute and --reviewed; only trusted scripts with permitted local effects are supported. Processes, -I, timeouts, reduced environment and hash audits do not contain hostile code or guarantee child-process cleanup. Untrusted execution is outside this build's domain.

Browser loopback, route/origin checks, CSP and SRI check delivery integrity. Reviewed JavaScript still has origin authority. Managed rollback covers tracked resources and the product's JSON Body adapter; unregistered effects are outside this contract. Drafts use local storage where supported. Activity is off by default, bounded and contains no document text.

Portable imports reject unsafe paths, symlinks, unpinned members and existing destinations. They transfer sources without execution/acceptance/deployment. Preview transport includes live Body data only with an explicitly provided source-bound checkpoint. New workspace identities invalidate carried GUI approval evidence. Keep personal memory, credentials, archives and drafts outside distributable source. Preserve licenses.

Native OS locking serializes writers. Interrupted pending actions require reviewed recovery of verified committed state. GUI capture context and actor/Baker labels are local attestations, not authenticated identities. Captures/images/history may contain private information and belong in private workspaces.
