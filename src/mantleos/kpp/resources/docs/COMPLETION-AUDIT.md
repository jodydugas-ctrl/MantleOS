# Completion scope and evidence

The table below describes inherited capability scope, not a fresh certification of the unified build. Current local outcomes and unrun browser/platform checks are recorded in the exported release evidence. Shared definitions and implementation are governed by [SYSTEMS.md](../SYSTEMS.md).

The commissioned deliverable is general KPP tooling. The supplied change request is reference data; Notepad Next is an example. The current implementation provides supported local workflows and explicit limits. Sample recipe approval belongs to its Baker.

## Limits

GUI discovery covers supplied .ui declarations, not runtime-generated/platform/accessibility exhaustiveness. Runtime records are explicitly manual observations; numeric image comparison does not establish semantic equivalence. Synthetic browser evidence is not native Qt or Notepad Next parity.

Managed rollback covers registered resources and the json-body/1 adapter. Arbitrary unregistered/hostile JavaScript, general cross-schema migration and shell replacement are unsupported. Local reviewed Python tests have no hostile-code sandbox. Universal code synthesis remains an Oven task within actual operator authority.

Core requires Python 3.11–3.14 standard library. Browser products need a browser; optional installed Playwright/Chromium/Node are verification tooling only. Locally executed Python versions and skipped checks are recorded in BUILD-OBSERVATIONS.json. Other runtime versions and hosted CI are unobserved; CI definitions alone confer no certification.

The source release excludes private drafts, identity, credentials, real Engrams, imported archives and development workspaces. Licenses remain. No remote service is configured by local implementation. KPP is the primary maintained project, with the shared implementation in mantleos.kpp. MantleOS remains associated through the same source.
