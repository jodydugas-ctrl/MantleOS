# Bounded adaptive integration

fit ranks Pantry labels. reflex-plan combines one recipe, static Scan and mapped obligations into an advisory source-pinned proposal. Attachment discovery is not approval or behavior evidence. examples/adaptive-reflex/request.json illustrates kpp.adaptation-request/1 with original/reflex/optional-absent mandatory Anchor IDs.

Staging supports root-level undecorated synchronous Python functions, one after-success adapter when dict['ok'] is True, and an optional observer. reflex-approval-template emits an incomplete attestation; the actual Baker reviews exact site/source/proposal. The Oven must not fill the decision itself.

reflex-stage writes a separate unchanged-source candidate plus adapter; reflex-audit checks bytes/inventory. Staging never executes, deploys or accepts it. Reviewed local tests and Baker acceptance are separate. Original Body behavior survives optional observer absence/failure. See EXECUTED-REFLEX-ANCHORS.md.
