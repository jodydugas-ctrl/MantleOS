# n8n Community Chase example, built with KPP

Anchor Studio retains Node-RED as its Body and uses n8n 2.46.4 Community as the
behavioral reference. This example demonstrates Chase construction and evidence.
The complete Community chase remains **BUILDING**. The original deep-Chase
recipe has 94 draft obligations; `anchor-studio-community-parity.json` preserves
them and adds 12 full-scope obligations. None of these declarations establishes
that all n8n functions have been implemented.

## Run the useful slice

Start your owner-configured Studio with `python -m mantleos studio run --nest
PRIVATE_NEST --node NODE_EXE --modules NODE_MODULES`. Open the printed loopback
address directly; no manual username/password is needed. The original Node-RED
automation editor is `/red/`. The Studio design canvas is a separate surface.

In the native editor import **if-journey.json** as a new flow, review it, and deploy
deliberately. Click **Manual sample items**. The true Debug output receives scores
10 and 11, the false output receives 9. Open the IF node to edit its typed rows,
AND/OR, case handling and continue-on-failure. Imports are data until the operator
explicitly deploys them. The fixture has no credentials, timer or network effect.

For a repeatable synthetic check without changing resident flows:

```powershell
$env:STUDIO_MODULES = 'ABSOLUTE_NODE_MODULES_DIRECTORY'
node examples/anchor-studio/journey-probe.cjs NEW_OUTPUT_DIRECTORY
```

Two fresh receiving processes run the actual persisted manual-trigger/IF/Debug
flow and verify branch contents, item pairing and unchanged saved source. No
HTTP listener, model provider or service is installed by the probe.

## Follow the KPP evidence trail

1. Pin the reference and inspect its handlers, parameters and conditions with
   `tools/studio_chase_inventory.py`. Static declarations are discovery data.
2. Read the existing canonical responsibilities with `kpp design-view --recipe
   recipes/anchor-studio-community-deep-chase.json --full-contract`.
3. Run `tools/studio_conditions_specimen.py --output NEW --node NODE_EXE --modules
   NODE_MODULES`. Its real satisfaction run retains direct, failed-regression,
   repair and native-runtime evidence against the integrated candidate.
4. Optionally provide `--reference N8N_WORKFLOW_PACKAGE_DIRECTORY` for the pinned
   reference-library comparison. Provisioning that dependency is an explicit
   owner operation; the example never installs it or calls a provider.
5. Review verification separately from Baker acceptance. Preserve earlier source,
   failing cases, live AppAI continuity and unresolved obligations when deepening.
