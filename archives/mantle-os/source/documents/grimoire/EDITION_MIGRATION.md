# Grimoire edition migration rules

Mantle OS 2.0.0rc1 carries two explicit Grimoire software lanes:

| Profile | Role | Counts and source |
| --- | --- | --- |
| `grimoire-v0.9` | Frozen compatibility | Historical edition file and legacy decoder. |
| `grimoire-v0.10` | Adopted default for new tissue | Explicit edition file, 209 BOOK statements, 295 composition rows. |

Counts are edition-scoped and derived from the selected code/source pair. A v0.9 record,
spore, or payload without a profile field uses only the documented historical v0.9 fallback;
content, filename, path, placement, or the current default never infers a new edition.

The v0.10 procedure exception permits zero HEAD only for all-STEP lead morphemes. Its
effective evidence and force come from explicit container metadata; missing metadata is
unresolved and non-governing. Statement parity is not transport integrity, and a quoted
profile is not adoption authority.

Research may produce eligibility and receipts, but it cannot authorize or adopt a candidate.
Only an independent operator or Body-policy adoption event may change the new-tissue default.
