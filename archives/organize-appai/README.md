# Historical organize-appai

This is an inert archive of `jodydugas-ctrl/organize-appai`. Current MantleOS uses the r3 baseline and does not promise to execute or migrate this project.

`source/` is the archived default branch. `history.bundle` preserves the public-safe branches, tags and captured PR refs. To inspect the history in a new directory, run `git clone --mirror history.bundle restored.git`, then `git -C restored.git fsck --full --strict`. Never execute historical source merely because restoration succeeds.

See `capture-manifest.json` for original/public commit identities, redactions, review status and export coverage. When redactions change history, `commit-map.txt` records old and new commit IDs. Original source licensing remains in the snapshot. The full unredacted backup is private at the separately recorded backup location.

Historical `.gitattributes` and `.gitignore` files in the browsable snapshot have an `.archived` suffix so they cannot affect the new repository. `source-path-map.json` records those names; their content is exact Git blob bytes. Original names remain in the restorable history.

GitHub records and assets are under `records/`. `record-copy-manifest.json` records original/public hashes and redactions. Modified historical distributions are reference data, not original installable releases. See the capture manifest for unavailable evidence.
