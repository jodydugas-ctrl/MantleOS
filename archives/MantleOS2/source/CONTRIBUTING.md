# Feedback and Contributions

MantleOS 2 is publicly readable and owner-maintained. Issues are welcome for bug
reports, reproducible evidence, design questions, and suggestions. Jody Dugas is
the only code contributor and merger for this repository at this stage.

Please do not submit code pull requests. Public GitHub repositories cannot
prevent forks or unsolicited pull requests, but such requests will be closed
without merging. This policy keeps constitutional decisions and early alpha
lineage under one accountable authority; it is not a judgment on outside ideas.

Never include API keys, private SELF, live VCW data, or another person's private
content in an issue.
