The current MantleOS product starts from the verified r3 container. These four older projects are inert reference material. Their branches, tags and captured pull-request refs are retained in restorable bundles, rather than merged into the new main history. No backward compatibility or migration is promised.

KPP is not archived: it remains the independent maintained development protocol.

Each archive contains a browsable default-branch snapshot, a Git bundle and a capture manifest. GitHub records/assets and review status are recorded in that manifest. Read the per-project README before restoration. Do not execute archived source during routine product testing.

Exact unredacted originals and the original r3 ZIP are retained separately at `A:\GitHub-Backups\2026-10-23`. Public copies omit identified born-organism identity, continuity and carrier material. When filtering changes commit identities, the archive includes the commit map. Original component licenses remain with their source. Checksums establish integrity, not authentication or authority.

Technical capture and content review are complete. Owner approval of the concrete review package is still required for public publication and repository deletion. Historical Actions logs/artifacts may already be unavailable; omissions must remain explicit.
