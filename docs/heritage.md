## Conflict register and decisions

| Conflict | Resolution for this foundation |
| --- | --- |
| CELL meaning | Smallest kernel-produced unit. Programs use tissue contracts; whole-cartridge metadata is ANATOMY.json. |
| Nine organs, no Brain, five systems | No universal count. Keep operational boundaries; default five groups remain compatible. MIND is optional. |
| Anchor language versus SCAN Anchor versus host anchoring | Use explicit language profile, scanner backend, and host integration terms; no interchangeable API. |
| `.vcw` used for several different containers | Explicit format selection and verified contents; suffix alone is insufficient. |
| Chroma RGB semantic tape versus Grimoire RGBA lanes | Separate codecs and editions; no inferred equivalence. |
| Body snapshot cloud upload versus incremental cloud memory | Preserve separate operations. The delivered protocol simulator handles incremental segments. |
| Private continuity versus distributable source | Synthetic fixtures only; private archives remain external even for private Git sync. |
| Carried identity revision path versus permanent Primer | New evolution API cannot change Primer or identity. Inherited explicit rebuild/rebirth paths are separate operator operations, not MIND powers. |
| Successful decoding/testing versus admission | Evidence and operator authorization remain distinct at use time. |
| Documented Linux receipts versus Windows delivery | Re-execute native Windows cases; fix actual flushing/publication failures without borrowing old receipts. |
| Cloud records versus executable state | Restore verified deterministic state receipts; require a matching full snapshot for executable/identity revisions. |
| Mixed source licenses | Preserve original terms and attribution; keep the new project private. |
| AppAI system directory versus SELF/NEST | Whole integrated host is SELF and NEST; `mantle/` is internal tissue. Portable Body export is not host migration. |
| Parent PRIMER versus mission instructions | Copy exact founding bytes; keep selected context in `MISSION.json`; never copy implicit authority or private history. |
| Legacy image active PRIMER versus embedded source specimen | Verify both, report divergence, explicitly select active carrier founding material for new birth. |

## Source-to-target map and changes

The packaged `runtime_lib/mantleos` becomes `src/mantleos`. No parallel runtime
tree is checked in. Portable runtime copies are generated artifacts. Cloud
protocol functions move from the Raven example toolkit into `continuity`;
`replication` binds them to verified Body recovery.

New cells, organism, evolution, and console modules compose existing providers.
The legacy namespace and its Book/RGBA/old-image adapters are removed.
Current cartridge/Chroma behavior is retained. KPP-aligned kernel CELL, tissue,
anatomy and shared Anchor contracts replace the earlier naming mismatch.

Integration corrections include Windows writable-handle flushing, atomic
create-only publication using Windows rename, protected blob names, staged
immutable blob writes, variable system counts, and executable/tissue consistency
checks. The Anchor journal portability correction changes an implementation pin;
it does not change the language primer or opcode semantics.
Standalone SCAN inspection no longer mistakes the current working directory for
a mounted Body; bound inspections retain the Body containment check.

The original Raven-specific handoff script expected private history and old
artifact names. It is not shipped or run against personal memory. A new synthetic
test exercises the actual binding/publication/stale-writer boundary instead.

## Streamlining decisions (a2)

Remove obsolete readers, their tests/dependency, and the superseded instruction-only
kit. Generate the repeated Notepad profile and share its Unicode table; preserve
byte-identical generated Anchor/browser output. Keep scanner backends, Chase,
semantic discovery, host handoffs, app creation/compilation, standalone receiver
bridges, current carriers, cold storage, AppAI missions, and cloud protocol code.
An inherited mechanism is not disposable merely because it is old. No arbitrary
size cap applies. Detailed prior receipts remain in local commit `5a8eb40`.
