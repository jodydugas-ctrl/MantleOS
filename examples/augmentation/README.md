# Selective augmentation example

From the project root with `PYTHONPATH=src`, run:

```console
python -m mantleos.augmentation --output .work/augmentation-example
```

Choose a new directory. Synthetic notebook operations share one native host
implementation, used by user actions and explicitly permitted fake-MIND actions.
The report records source pins, each read/edit/save pathway, actual UTF-8 bytes,
MIND failures, denied actions, sensor failure and retained history. Source copies
and executable Body tissue remain available for inspection and rollback.
The generated construction workspace remains BUILDING, without Baker acceptance.

The full suite also injects failed saves, interrupted publication and concurrent
edits. This qualifies the bounded example; it is not complete Hermes integration
or a measured claim of model capability amplification. No provider is contacted.

The Python host adapter reuses the existing NOTEPAD_LLM/1.3 Body profile.
The recipe selects Python for the host/adapter and leaves recipe Anchor binding
unselected; this does not remove the established Body implementation.
